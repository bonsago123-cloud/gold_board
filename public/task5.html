과제 5 · 대화가 끊겨도 이어지는 프로젝트

비트코인 차트 인수인계 결과

저장된 실행 기록을 불러오는 중입니다.

정보판 · 소스 저장소

무엇을 완성했나

첫 작업자는 차트 영역·선택 UI·출처 안내까지만 작성하고 멈췄다. 다음 작업자는 남은 BTCUSD 차트 연결, 시간 간격 변경, 다시 불러오기, 오류 안내와 복구를 구현했다. 현재가·원화·금·은 기능은 유지했다.

작업자 수와 역할 이름은 고정하지 않는다. 한 작업자가 끝내지 못하면 저장소와 일곱 항목 인수인계를 다음 작업자가 이어받는다. 이번 두 실행을 과제 비교 대상으로 사용했다.

이름을 가린 비교표

실행작업시간요청 수실패 회차종료 검사공통 상한

실패 회차는 고정10개 중 하나 이상 FAIL이 나온 실행 횟수다. 계획적으로 미완성인 상태에서 실행한 회차도 포함한다. 시간은 세션 시작부터 종료까지의 기록값이다. 재작업량은 수기로 적지 않고 제출 후 고정 소스 버전으로 계산한다. 이 표의 속도만으로 도구의 우열을 정하지 않는다.

작업 순서

    현재 시스템은 새 AI를 자동 호출하지 않는다. 사용자가 대화를 시작하면 시작 기록·검사·종료 기록·인수인계 저장을 명령으로 수행하고, 업로드 뒤 Actions가 검사를 실행한다.

    처음 고정한 같은 검사 10개

    검사 정의·실행 코드·최초 요청은 SHA-256으로 고정했다. 두 실행 사이 검사 삭제·기대값 변경·완화 없이 같은 검사를 사용했다.

        측정 및 제출 증거의 범위

        서로 다른 서비스 사용은 보존된 세션 기록으로 구분하며 모델명을 추정하지 않는다. 기능 완성과 과제 채점 승인은 별개다. 이전 대화 전문·실명·연락처·비밀값을 이 보고서에 넣지 않았다.

        실패와 성공을 거쳐 개선한 점

        1. 이전 구리 작업에서는 인계 기록을 남겼지만 실제 조회 문제를 해결하지 못했다.
        2. 이후 구현 결과와 검사 기록을 구분하고, 중단 상태와 다음 행동을 인계하도록 보완했다.
        3. 이전 차트 검사에서는 탭 선택 누락 등 검사 자체의 오류가 있었다. 그 실험과 기록은 보존했다.
        4. 이번 새 사이클은 수정된 기준을 먼저 고정하고 부분 구현을 다른 작업자가 완성했다. 과거 검사 결과와 이번 결과는 합산하지 않는다.

        짧은 확인 방법 · 4줄

        ① 위치: 이 공개 보고서와 연결된 소스 저장소를 연다.

        ② 행동: 비교표 확인 → 같은 고정10개와 인계 해시 확인 → 정보판의 비트코인 탭에서 차트를 확인한다.

        ③ 통과 모습: 4/10에서 10/10으로 이어진 기록, 동일한 인계 원문·해시, 정상 차트가 보인다.

        ④ 안 될 때 모습: FAIL·UNVERIFIED 또는 기록 로딩 오류가 표시되고, 외부 차트가 실패하면 안내와 다시 불러오기 버튼이 보인다.

        AI와 나의 판단 · 3줄

        ① AI에게 맡긴 일: 반복 인계 체계 구성, 차트 부분 구현과 이어서 완성하기, 고정 검사와 기록 정리.

        ② 직접 판단한 일: 작업자 수를 둘로 고정하지 않고, 중간에 멈춰도 다음 작업자가 이어받도록 요구했다. 첫 작업자는 일부만 구현하도록 정했다.

        ③ AI 제안을 따르지 않은 일: 완성된 기능을 계속 재검사하는 방향 대신, 차트를 다시 시작해 실제로 남은 구현을 다른 AI가 이어받도록 결정했다.

        다음 도구 선택 기준 — 제출자 확인용 문장: 저장소와 인수인계만으로 남은 기능을 완성하고, 같은 검사를 통과하며 실제 시간과 요청 수를 기록하는 도구를 우선한다.
