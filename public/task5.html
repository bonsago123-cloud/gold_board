현재는 부분 구현 단계

이전 차트는 제거하고 차트 영역·선택 UI·출처 안내까지만 만들었습니다. 실제 차트 연결과 간격 변경·재시도는 다음 작업자가 이어서 완성합니다. 현재가·원화·금·은 탭은 유지합니다.

고정 검사: 시작 0/10 → 부분 구현 4/10. 미통과 6개는 다음 구현 범위이며 완료로 처리하지 않습니다.

작업자 수를 정하지 않는 인계

각 작업자는 저장소와 현재 인수인계를 읽고 재개합니다. 끝내지 못하면 검사 결과·변경 내용·남은 문제·다음 행동을 저장합니다. 다음 작업자가 같은 과정을 반복합니다.

새 AI 대화는 사용자가 시작합니다. 검사·상태·기록·인계 저장은 명령과 GitHub Actions로 자동화합니다.
