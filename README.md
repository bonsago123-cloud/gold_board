# METAL / NOTE v1.8.0

과제 검증 페이지를 현재 금·은·석유(WTI)·밀 정보판 구성에 맞게 개편했습니다. 초기 가격 카드, 숨겨진 종목 탭과 오래된 설명을 제거했습니다.

- 현재 종목 구성: 메인과 같은 설정에서 출처·단위·갱신 방식·증빙 여부를 표시합니다. 종목 링크는 메인의 해당 탭으로 이동합니다.
- 금 기록 대조: 메인과 같은 저장 기록을 읽습니다. 페이지 진입과 저장 기록 새로 읽기는 GET만 사용합니다. 금 원천 조회·기록 버튼은 POST로 실제 수집합니다.
- 실제 이틀 증빙: 최초 두 실제 KST 날짜, 원자료·저장값·화면값, 변화값 및 JSON 다운로드를 유지합니다.
- 공식 합성 검사: package ID·17개 파일 SHA-256·원본 fixture 순서 검사 유지. 자체 합성 시험도 실제 기록과 분리합니다.
