# METAL / NOTE v1.9.0

금·은·석유(WTI)·밀을 모두 검증 페이지의 기능 확인 대상으로 포함했습니다. 실제 일별 저장·이틀 증빙의 과제 대표 대상은 금으로 유지합니다.

- 금: 원자료·저장값·화면값 대조, 실제 이틀 증빙, 자체/공식 실패·복구 검사.
- 은: 실제 가격·출처·단위·두 시각·KST 확인, 같은 메인 조회 코드를 사용하는 다섯 합성 실패·마지막 정상값 보존·복구 검사. 검증 페이지의 실제 조회와 합성값은 별도 상태입니다.
- 석유·밀: 종목·출처·단위, 실제 가격·차트, 수동 갱신, 자동 갱신·중지, 차트 시간 단위의 사용자 확인 항목을 각각 제공합니다. 처음에는 미확인이고, 직접 확인함/문제 있음과 확인 시각·메모를 이 브라우저에 저장합니다. 외부 가격 수신 성공은 자동 판정하지 않습니다.
- 부가 종목 결과 JSON: 은 실제 조회와 합성 검사 결과, 석유·밀 사용자 확인 결과를 구분해서 다운로드합니다. 금 이틀 증빙이나 공식 T04 판정·과정 영수증을 대체하지 않습니다.

Vercel에 ZIP의 파일을 반영해 재배포하세요. Supabase 변경이나 새 환경변수는 없습니다. 과제 검증(/verify.html)의 ‘은·석유·밀 검사’에서 시작하세요.

검사 결과: 자동 테스트 23개, 금/공식 검증 및 메인 갱신·부가 종목 검사 UI 동작 검사 통과. 실제 배포 화면·외부 시세 수신·실제 이틀 영수증은 별도로 확인해야 합니다.
