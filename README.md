# v1.6.1 · 외부 위젯 종목 제한 수정

석유·밀의 거래소 연속선물 위젯이 TradingView 전용 종목 제한으로 표시되지 않아 OANDA:WTICOUSD, OANDA:WHEATUSD로 변경했습니다. 두 종목은 CFD 참고가격이며 거래소 선물 체결가와 다릅니다. 밀의 기존 센트 단위 안내도 제거하고 OANDA의 USD 호가 기준으로 표시합니다.

파일 반영 후 Vercel 재배포 및 강력 새로고침(Ctrl+F5)을 하세요. Supabase와 환경변수 변경은 없습니다. 외부 iframe 실제 표시는 배포 후 확인이 필요합니다.
