# METAL / NOTE v3 — 금 과제 검증 · USD/KRW

과제 검증 대상은 금(XAU) 하나입니다. 금 메인 화면과 검증 페이지는 같은 gold_* 기록을 사용합니다. 추가 원자재 성공 여부나 환율 실패는 금의 검증 판정에 영향을 주지 않습니다.

메인에는 금·은·석유·밀 탭을 유지하고, 각 종목에서 달러 원천값과 최신 제공 환율로 계산한 원화 참고값을 함께 표시합니다. 석유·밀은 기존 유료 원천 연결이 없으면 숫자 값을 표시할 수 없습니다. 외부 차트는 원화 환산/과제 증빙에 사용하지 않습니다.

적용 순서: **docs/업데이트-적용.md**. 금 검증과 환율에 새 키·결제는 필요 없습니다. 네 종목 버전에서 수집한 금 기록은 sql/003_restore_gold_records.sql로 보존하여 옮길 수 있습니다.

환율 출처: https://www.exchangerate-api.com/docs/free (하루 1회 갱신, 키 불필요). 페이지에 출처 링크와 환율 기준 시각·조회 시각을 표시합니다. 환산에는 전체 정밀도의 원가격/환율을 사용하고 원화 표시만 1원 단위 반올림합니다.

검증: npm test, npm run build, npm run verify:assets. 화면 DOM 동작 검사와 SQL 이관 검사는 scripts/check-gold-fx-dom.mjs 및 scripts/check-gold-migration.mjs를 참고하세요.

배포 후 실제 시세 조회·DB 기록과 두 날짜 증빙을 확인해야 합니다. 합성 검사로 실제 날짜를 대신하지 않습니다.
