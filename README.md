# METAL / NOTE v1.7.0

금·은·석유(WTI)·밀의 가격과 차트를 표시합니다. 레늄 탭과 전용 API·환경변수 설정을 제거했습니다.

석유·밀의 상단 갱신 버튼은 현재 시세 위젯과 차트를 함께 다시 불러옵니다. 자동 갱신을 켜면 보고 있는 탭을 30초 이상 간격으로 다시 불러오며, 다른 브라우저 탭을 보는 동안 멈춥니다. 차트의 시간 간격 선택은 유지합니다. 차트의 다시 불러오기 버튼도 현재 시세를 함께 다시 불러옵니다.

석유·밀은 TradingView/OANDA CFD 참고가격입니다. 화면 요청 시각은 실제 가격 기준 시각이 아닙니다. 제공자의 휴장·지연·오류로 값이 그대로일 수 있고, 화면 재요청은 최신 거래나 수신 성공을 보장하지 않습니다. iframe 내부 가격을 읽거나 금의 일별 기록으로 저장하지 않습니다.

- 과제 조건: `docs/추가기능-조건검토.md`
- 처음 설치: `docs/설치안내.md`
