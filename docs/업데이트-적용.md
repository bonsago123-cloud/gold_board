# 기존 사이트에 적용하기

1. 기존 GitHub 저장소를 이번 ZIP의 `gold-board` 폴더 안 파일로 업데이트합니다. `public`, `scripts`, `tests`, `docs`, `package.json`, `package-lock.json`, `vercel.json`을 포함하세요. 실제 키가 있는 `.env.local`은 올리지 않습니다.
2. Vercel 자동 배포가 끝나면 사이트에서 Ctrl+F5를 누릅니다.
3. 자동 갱신 체크박스, 과거 차트 시간 간격, 금 뉴스, 공식 T04 검사 링크를 확인합니다.

**기존 Supabase SQL·데이터·환경변수를 그대로 사용합니다. DB 초기화나 추가 SQL 실행, 새 API 키는 필요 없습니다.** 신규 설치만 기존 SQL을 실행합니다.

`vercel.json`에는 TradingView 공식 위젯의 스크립트·iframe 허용이 추가됐습니다. 빠뜨리면 차트·뉴스가 차단될 수 있습니다.

- 현재 시세: 30초 이상 간격 자동 조회. 표시되는 원천 시각과 조회 시각 확인. 가격은 거래가 없으면 그대로일 수 있습니다.
- 차트: 1분/5분/15분/1시간/4시간/1일/1주/1개월 선택. 확대·축소와 좌우 이동으로 x축 표시 기간 조절.
- 뉴스: XAUUSD 관련 최신 제목·제공자·기사 시각 확인. 수동 새로고침과 화면이 열린 동안 10분 간격 갱신.
- 공식 검사: 공식 T04 검사 → 17/17 파일 SHA-256 일치 → 공식 전체 순서 검사.

차트와 뉴스는 TradingView가 공급하는 외부 화면입니다. 배포 환경의 네트워크에서 표시를 확인해야 합니다. 오류 때 다시 불러오기와 출처 링크를 이용하세요. 원문 기사의 언어·로그인·유료 여부는 각 제공자의 정책을 따릅니다.
