확인 방법:

- 시간 간격 1분~1개월을 변경하고 차트에서 확대·축소해 x축 기간을 바꿉니다.
- 상단 금 일별 기록·증빙은 종목을 바꿔도 금으로 유지됩니다.
- 자동 조회는 30초 간격이며 숨긴 탭이나 합성 시험 중에는 정지합니다. 원천 제한 때는 대기합니다. 휴장·오래된 원천값은 상태와 시각을 확인합니다.

실패하면 해당 종목의 마지막 정상값과 원래 시각을 유지하고 오류를 표시합니다. 금과 은의 마지막 정상값은 페이지 메모리에서 각각 유지되며 새로고침하면 추가 조회값은 다시 가져옵니다. 영구 저장되는 과제 증빙은 기존 금 일별 기록입니다.

과제의 실제 이틀 증빙 및 과정 영수증은 별도로 확인해야 합니다. 과거 차트나 은 조회가 이를 대신하지 않습니다.
