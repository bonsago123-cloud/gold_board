# v1.9.0 모든 원자재 기능 검증

ZIP의 gold-board 내용을 반영해 Vercel에 재배포한 뒤 /verify.html에서 Ctrl+F5를 누릅니다. 새 commodity-verify.mjs, silver-client.mjs, silver-checks.mjs를 포함하세요. 메인 dashboard.mjs도 공유 은 조회 코드를 사용하도록 변경됐습니다. Supabase SQL·환경변수 변경은 없습니다.

‘은·석유·밀 검사’에서 은 실제 조회와 자체 합성 검사를 각각 실행합니다. 석유·밀은 메인 종목 링크를 새 탭으로 열어 각 동작을 확인하고, 확인한 결과를 직접 선택합니다. 결과는 자동 통과로 처리되지 않습니다. 수동 기록은 이 브라우저에만 보관되므로 제출·공유하려면 부가 종목 결과 JSON을 다운로드하세요. 배포가 바뀌면 종목별 확인 기록을 초기화하고 다시 검사합니다.
