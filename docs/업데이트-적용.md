# v3.1 — 금·은만 표시

1. Supabase SQL Editor에서 **sql/004_gold_silver_only.sql** 전체를 실행하세요. 기존 002 SQL을 설치한 사용자의 금·은 수집용 함수만 변경합니다. 기존 금·은 및 기타 과거 기록은 삭제하지 않습니다.
2. 002를 실행한 적이 없다면 001_gold_board.sql → 002_four_assets.sql → 004_gold_silver_only.sql 순서로 실행합니다. 002는 이전 구조 설치용이며, 최종 수집 대상은 004에서 금·은으로 제한합니다.
3. 앞선 네 종목 버전에서 수집한 금 기록을 아직 금 전용 저장소로 옮기지 않았다면 003_restore_gold_records.sql도 실행하세요. 날짜를 조작하지 않고 기존 금 기록만 보존하여 복사합니다.
4. ZIP의 gold-board 폴더 안 내용을 저장소 같은 위치에 덮어쓰고 Vercel에 재배포하세요. 배포 완료 후 Ctrl+F5.
5. 메인에는 금·은 탭만 표시됩니다. 두 종목 모두 달러·원화 표시, 차트, 일별 기록을 유지합니다. 금 과제 검증은 금 하나만 사용합니다.

새 API 키는 필요 없습니다. COMMODITIES_API_KEY는 더 이상 사용하지 않으므로 Vercel에서 삭제해도 됩니다. 기존 Supabase 환경변수는 유지하세요.

환율은 하루 1회 갱신되는 최신 제공 USD/KRW 참고 환율입니다. 과제 원자료 대조와 실제 이틀 변화값은 USD 기준입니다. 환율 조회 실패 시 마지막 환율과 표시된 기준 시각을 확인하세요.
