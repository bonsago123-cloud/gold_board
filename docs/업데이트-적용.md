## 변경된 화면

상단에 금·은·백금·팔라듐 버튼이 있습니다. 클릭하면 같은 정보판에서 큰 가격, 제목, 출처 URL, 원천 시각, 조회 시각, 상태, 조회 버튼, 차트 종목이 함께 바뀝니다. 각 종목은 USD/트로이온스 단위입니다. 별도의 아래쪽 금·은 카드와 선택 상자, 페이지 내 이동용 ‘금·은 시세 / 차트’ 메뉴를 제거했습니다.

차트 시간 간격은 1분~1개월이며 종목을 바꿔도 선택 간격을 유지합니다. 확대·축소·좌우 이동으로 표시 기간을 바꿀 수 있습니다. 가격은 Gold API, 차트는 TradingView/OANDA로 출처가 달라 값·시각이 다를 수 있습니다.

자동 조회는 선택한 종목만 30초 이상 간격으로 실행합니다. 숨긴 탭/합성 시험 중에는 멈추고 호출 제한 대기를 지킵니다. 종목별 마지막 정상값을 별도로 유지합니다. 다른 종목의 늦은 응답이 현재 정보판을 덮어쓰지 않습니다.

## 과제 기록

금 탭의 기존 Supabase 일별 기록과 실제 이틀 증빙을 유지합니다. 다른 종목 탭은 현재 시세와 차트를 제공하며 금 기록 표를 숨깁니다. ‘금 기록 보기’를 누르면 금 정보판으로 돌아갑니다. 다른 종목의 마지막 값은 현재 페이지 메모리에서만 유지됩니다.

실패 재생실은 ‘합성 금 시험값’이라고 표시합니다. 공식 T04 검사는 기존 별도 화면에서 실행합니다. 실제 이틀 및 과정 t04_day 영수증, 공개 결과물·full commit 소스 URL 확인은 별도로 필요합니다.

## 배포 후 확인

상단 네 종목을 차례로 눌러 가격·출처·차트의 종목이 일치하는지 확인하세요. 금 탭에서 기존 날짜별 기록과 증빙을 확인하세요. 외부 차트가 비어 있으면 다시 불러오기 및 차트 하단 출처 링크를 사용하세요. 외부 위젯의 실제 브라우저 렌더링은 배포 후 확인해야 합니다.
