# 인수인계 템플릿

## 1. 목표
현재 기능 한 개의 완료 목표를 적는다.

## 2. 현재 상태
이미 구현된 것과 아직 구현되지 않은 것을 구분해 적는다.

## 3. 실행 명령
새 작업자가 저장소만 받아도 실행할 수 있는 명령을 적는다.

## 4. 통과 검사
고정 검사 ID별 현재 PASS/FAIL을 적는다. 검사 원문은 바꾸지 않는다.

## 5. 남은 문제
실패 중인 동작과 재현 조건을 적는다.

## 6. 다음 행동
다음 AI가 가장 먼저 해야 할 구체적인 행동을 적는다.

## 7. 건드리지 말 것
회귀를 막기 위해 수정 금지 또는 주의 영역을 적는다.
