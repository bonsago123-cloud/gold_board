# 레늄 가격 연결

1. https://metals-api.com 에서 RHENIUM 최신 및 timeseries 접근이 가능한 API 키를 발급받습니다. 이용 요금과 공개 사이트에 가격을 표시할 수 있는 이용 범위를 확인합니다.
2. Vercel 프로젝트 → Settings → Environment Variables에 `METALS_API_KEY`를 추가하고 발급받은 키를 값으로 넣습니다. Production에 적용합니다. 키를 소스나 채팅에 적지 마세요.
3. 재배포 후 레늄 탭에서 가격·출처 timestamp·조회 시각과 최근 30일 차트를 확인합니다.

키가 없으면 ‘연결 대기’, 권한 또는 호출 한도가 부족하면 오류를 표시합니다. 금·은·석유·밀에는 이 키가 필요하지 않습니다. Supabase 변경도 없습니다.

최신 가격은 1시간 간격 조회/공유 캐시, 과거 30일 결과는 24시간 공유 캐시입니다. 과거 데이터는 UTC 어제까지의 일별 관측점이며 누락일을 보간하지 않습니다. 시간 간격 메뉴는 레늄에서 비활성화됩니다. 다른 종목은 기존 1분~1개월 메뉴를 사용합니다.

제공자의 문서에 따라 USD 기준 RHENIUM 환율의 역수(1/rate)를 USD/트로이온스로 표시합니다. ‘원천 시각’은 데이터 수집 timestamp이며 실제 레늄 거래 갱신 시각과 다를 수 있습니다. 초 단위 실시간 거래가격이라고 표시하지 않습니다. 화면에서 15분 이상 지난 값은 오래된 값으로 표시할 수 있습니다.

키를 받지 않은 상태에서 최신/과거 실응답은 검증하지 못했습니다. 예제 기반 환산과 오류 처리 테스트를 통과했습니다. 계정 요금제의 실제 응답과 단위/기준을 확인한 후 사용하세요.
