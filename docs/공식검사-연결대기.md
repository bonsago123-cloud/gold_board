# 공식 T04 자산 연결 대기

과제 조건에는 아래 경로와 다운로드 버튼 이름만 있고 실제 다운로드 URL 또는 ZIP 내용은 없습니다.

`assets/studio-task-assets/t04-real-information-board/`

필요한 원본:

- README.md
- public-contract.json
- asset-manifest.json
- fixtures 9종
- criterion-registry와 schema
- 참조 adapter 및 초기화·재생 안내

현재 `public/fixtures.mjs`의 `LOCAL-*`는 자체 제작 시험입니다. 공식 package ID를 임의로 만들지 않았고, 공식 SHA-256과 일치한다는 주장도 하지 않습니다. 공식 `T04-RECOVER-D2`의 정확한 구조·코드·기댓값은 미확인입니다.

## 원본을 받은 뒤

1. 원본 ZIP과 공식 배포 페이지/다운로드 주소를 보관합니다.
2. README와 public-contract.json을 먼저 읽고 package ID, schema, fixture 이름과 기대 상태를 확인합니다.
3. asset-manifest.json의 형식에 따라 원본 파일 SHA-256을 대조합니다. ZIP에서 계산한 값을 다시 정답으로 삼지 않습니다.
4. 제공된 참조 adapter를 합성 모드로 초기화해 D1-A→D1-B→실패5종→공식 T04-RECOVER-D2를 재생합니다.
5. 이 앱의 `fetchQuote`, `success`, `failure`와 연결하는 adapter를 **확인된 계약에 맞게** 작성하고 공개 재생실에 연결합니다. 현재 자체 fixture와 비슷해 보여도 단순히 이름만 바꾸면 안 됩니다.
6. 같은 날 여러 성공 1행, 복구 시 다음 날짜 정확히 1행 추가, fresh/none과 원자료 보존을 확인합니다.
7. package ID·파일별 hash 대조·공식 검사 결과를 증빙에 추가하고 화면의 미검증 문구를 실제 결과에 따라 수정합니다.

배포자가 SHA256SUMS 형식 목록을 제공하거나, 공식 JSON 계약을 확인한 뒤 손실 없이 변환했다면 다음 보조 도구를 사용할 수 있습니다.

```bash
npm run verify:assets -- /공식꾸러미폴더 /배포자가제공한/SHA256SUMS
```

이 도구는 hash만 대조하며 공식 adapter 실행을 대신하지 않습니다. 미제공 상태의 명령은 종료코드 2로 끝나므로 통과로 오인하지 않습니다.
