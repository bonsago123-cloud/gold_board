# 설치 및 재배포

기존 사용자는 먼저 **업데이트-적용.md**를 따르세요.

1. Supabase 프로젝트의 SQL Editor에서 sql/001_gold_board.sql을 실행합니다. 기존 gold_* 테이블은 삭제하지 않습니다.
2. Vercel에 SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY를 서버 환경변수로 등록합니다. 브라우저 코드나 Git에 비밀키를 넣지 않습니다.
3. ZIP의 gold-board 폴더 내부를 GitHub 저장소 루트에 올리고 Vercel 프로젝트에 연결합니다.
4. 재배포 후 금 탭의 금 조회·기록을 누릅니다. 금 USD 원천값과 원화 환산값, 각각의 기준 시각을 확인합니다. 환율에는 API 키가 필요 없습니다.
5. /verify.html에서 금 조회·기록·검증 → 금 실패·복구 검사 → 공식 전체 순서 검사를 확인합니다. 다른 실제 KST 날짜에 금을 다시 조회해 두 날짜 증빙과 변화값을 대조합니다.
6. 결과물 URL과 full commit 소스 URL을 시크릿 창에서 확인합니다. 실제 두 날짜 및 과정 영수증 조건은 제출 전에 확인합니다.

예약 수집을 사용하려면 CRON_SECRET을 설정합니다. 예약은 매일 UTC 00:10(KST 09:10) 금 수집입니다. 플랫폼 예약 제공 조건은 계정을 확인하세요.

## 추가 원자재

은·석유·밀 탭의 저장 기능에는 기존 sql/002_four_assets.sql이 필요합니다. 석유·밀은 COMMODITIES_API_KEY와 해당 종목 이용 권한이 추가로 필요하며, 금 과제 검증에 필수가 아닙니다. 키 미설정 상태에서 석유·밀의 숫자값과 원화값은 표시할 수 없습니다.

기존 네 종목 버전의 금 기록을 금 전용 저장소로 보존하여 옮기려면 sql/003_restore_gold_records.sql을 실행하세요. 새로 조회한 것처럼 날짜를 변경하지 않습니다.
