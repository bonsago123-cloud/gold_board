# 과제5 제출문

결과물 주소: https://goldboard-omega.vercel.app/task5.html
소스 주소: https://github.com/bonsago123-cloud/gold_board

## 작업 요약
저장소와 일곱 항목 인수인계로 다음 AI가 이어받는 절차를 만들었다. 구리 작업의 실제 원천404 실패를 기록하고 절차를 보완했다. 비트코인 현재가 기능은 첫 실행2/10에서 다음 실행의 동일 고정 검사10/10으로 완성했다. 이후 차트·탭·공통 UI·원화 표시와 수정 차트 검사도 완성했다. 과거 실패는 보존했다.

## 짧은 확인 방법 4줄
위치: 공개 보고서의 익명 비교표와 작업 순서.
행동: 비교표 보기 → 종료 검사 기록 열기 → 받은 인수인계 원문 보기.
통과 모습: 같은 현재가 검사10개와2/10→10/10 결과, 순서가 맞는 소스 버전, 동일 인계 해시.
안 될 때 모습: 링크 접근 실패·ID 또는 해시 불일치·필수 증빙 누락이면 확인 불가.

## AI와 나의 판단 3줄
AI에게 맡긴 일: 인수인계 절차, 비트코인 구현, 검사와 실패·성공 기록 정리.
직접 판단한 일: 구리 대신 비트코인 선택, 금·은과 같은 탭·UI와 원화 표시 요구, 최종 사이트 동작 확인.
AI 제안을 따르지 않은 일: 완성한 기능을 다시 검사하거나 새 일을 만들자는 제안 대신 기존 실패와 성공 과정으로 제출하기로 결정.

## 제출 전에 사실 확인이 필요한 부분
- 현재가 첫 실행과 다음 실행에서 실제 사용한 서비스·모델명. 기록에는 모델 차이가 미확인이다. 무료 AI 사용 여부도 확인한다.
- 다음 실행에 이전 대화가 실제로 제공되지 않았는지. 저장소 기록은 엄격한 맥락 격리를 독립 증명하지 못한다고 명시한다.
- 본인의 도구 선택 기준. 제안: “저장소만으로 이어받아 같은 검사를 통과시키고 시간과 요청 수를 적게 쓰는 도구를 먼저 선택한다.” 학생 확인 전에는 확정 판단이 아니다.
- 이 보고서 업로드 후 공개 URL의 무로그인 접근. 현재가 비교를 중심 증거로 사용하며 수정 차트10/10을 원본 고정 차트10/10으로 쓰지 않는다.

기능 재구현 또는 새 실험을 요구하는 문서가 아니다. 기존 증빙을 정리한 제출본이며 모든 과제 조건의 통과를 단정하지 않는다.
