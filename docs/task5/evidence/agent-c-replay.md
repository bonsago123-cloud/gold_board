## 다음 사용자 행동
업로드 ZIP을 풀어 내부 파일과 폴더를 저장소 루트에 올린다. ZIP 자체를 저장소에 올리는 방식은 적용되지 않는다. .github/workflows/handoff-check.yml도 포함한다. GitHub 업로드 후 Actions는 같은 검사를 실행하고 실패 시에도 handoff-evidence 아티팩트를 보관한다. 실제 GitHub 실행 결과는 업로드 뒤 확인해야 한다.

현재 목표는 완료되지 않았다. 원래 조건의 제공자 API가 복구되거나 고정 조건 변경에 관한 별도 사용자 결정이 필요하다. 후속 AI에게는 저장소와 “인수인계 문서를 읽고 이어서 진행해”를 전달하면 된다.

추가 관찰: 검사 도중 문서 변경이 감지된 회차는 integrity FAIL로 차단되었다. 해당 회차를 보존하고 모든 파일 기록을 마친 뒤 다시 실행한다.
