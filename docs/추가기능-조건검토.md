# v1.4 과제 조건 검토

첨부 `과제4 조건.txt`와 공식 공개 계약의 목표는 값 하나의 원천·저장·표시 대조, 일별 기록, 다섯 실패 보존·복구, 실제 이틀 증빙입니다. 추가 원자재 탭이나 차트를 금지하는 조항은 없습니다. 기존 금 증빙의 의미를 유지하는 아래 설계는 해당 조건과 충돌하지 않는 것으로 판단합니다. 실제 배포와 증빙까지 모두 통과했다는 의미는 아닙니다.

| 대상 | 구현 및 조건 보호 |
| --- | --- |
| 주 증빙 대상 | 금 XAU 고정. 기존 Supabase 테이블·날짜 키·최초 이틀 기록 유지 |
| 추가 종목 | 은 XAG, 백금 XPT, 팔라듐 XPD. 현재 시세·차트를 같은 정보판에 표시 |
| C03~C09 | 종목별 실제 값·USD/트로이온스·출처 URL·원천 시각·조회 시각·Asia/Seoul 표시 |
| C10, C20~C24 | 금 탭에서만 일별 원자료·저장값·화면값 및 이틀 비교 표시. 다른 종목을 금 기록으로 저장하지 않음 |
| C11 | 금속 원천은 API 키 불필요. 기존 Supabase 비밀값은 서버 환경변수 유지 |
| C12~C19, C26 | 기존 자체/공식 합성 검사 유지. 합성 화면은 실제 종목 가격과 구분 |
| 과거 차트 | Gold API와 다른 TradingView/OANDA 출처라고 표시. 실제 이틀 증빙을 대신하지 않음 |
| 화면 전환 | 상단 종목 버튼으로 제목·현재 가격·시각·출처·차트가 함께 변경. 실패 시 해당 종목 마지막 정상값 유지 |

네 종목 모두 귀금속이며 트로이온스 단위로 표시합니다. 구리·원유 등 단위/계약이 다른 상품은 이번 버전에 포함하지 않았습니다. 뉴스 기능은 없습니다.

남은 실제 제출 조건: 서로 다른 실제 KST 날짜의 금 기록, 과정 사이트가 발급하는 t04_day 영수증 2건의 일치, 무로그인 공개 결과물 URL 및 전체 commit이 포함된 HTTPS 소스 URL. 파일과 합성 검사만으로 이러한 조건을 완료 처리하지 않습니다.

참고 원천: https://gold-api.com/llms.txt
차트 종목: OANDA:XAUUSD / OANDA:XAGUSD / OANDA:XPTUSD / OANDA:XPDUSD

## v1.5 검증 화면 분리

검사·대조·증빙·제출 안내를 무로그인 공개 `/verify.html`로 이동했습니다. 메인 하단 링크에서 접근 가능하며 조건에 필요한 기능을 삭제하지 않았습니다. 실제 원천 실패 안내와 마지막 정상값 보존은 메인에도 유지합니다. 메인의 금 일별 기록을 제외한 과제 전용 자료는 검증 페이지에서 확인합니다.

## v1.6 종목 교체

백금·팔라듐을 제거하고 레늄·WTI 원유 연속선물·시카고 밀 연속선물을 추가했습니다. 금의 일별 저장과 이틀 증빙은 동일합니다. 추가 탭을 금의 증빙에 섞지 않습니다. 레늄은 API 키를 서버 환경변수에서만 사용하고 upstream URL/키를 응답에 노출하지 않습니다. 석유는 USD/배럴, 밀은 미국 센트/부셸을 표시하고 선물·지연 가능성을 안내합니다. 레늄 원천 timestamp는 거래 체결 시각으로 주장하지 않습니다. 실제 키/과거 데이터 권한 및 외부 위젯 렌더링은 배포 후 확인 대상입니다.
