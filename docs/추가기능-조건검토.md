# 추가 기능의 조건 검토

검토일: 2026-09-30. 근거: 첨부 조건 TXT 및 공식 public-contract.json / criterion-registry.json.

**세 기능을 금지하는 조항은 없습니다.** 금이라는 한 신호를 중심으로 부가 정보를 제공하되 기존 실제 이틀 증빙·실패 보존 규칙을 유지하면 문서상 조건과 충돌하지 않습니다. 강사·마스터의 최종 승인이나 배포 후 전 항목 통과를 뜻하지는 않습니다.

| 요청 | 구현 | 조건 준수 |
|---|---|---|
| 과거 시세·시간축 | OANDA:XAUUSD 공개 과거 차트, 분·시간·일·주·월 | 과거 데이터를 실제 날짜 조회로 소급 저장하지 않음. x축 기간은 확대·축소/이동, 집계 간격은 선택 메뉴 |
| 현재 시세 실시간 | Gold API를 30초 이상 간격 자동 조회 | 초당 체결 스트리밍이 아님을 명시. 원천 시각·조회 시각 유지, 같은 날짜 1행 갱신, 실패 시 정상값 보존 |

과제용 실제 가격은 Gold API입니다. 참고 차트는 OANDA이므로 가격·시각이 다를 수 있어 출처를 각각 표시합니다. 차트 값을 Gold API 원자료·저장값 비교에 사용하지 않습니다. Gold API 과거 조회에는 별도 키와 요금 조건이 있어 이번에는 키 없는 공개 차트 위젯을 사용했습니다.

자동 조회는 원천의 30초 캐시 권고와 서버 next_attempt_at/Retry-After를 따릅니다. 연속 실패 때 60초부터 최대 5분까지 기다리고, 다른 탭을 보거나 합성 시험 중이면 조회를 멈춥니다. 휴장·갱신 지연은 오래된 값 표시로 확인합니다.

외부 차트에 내용이 없으면 가짜 데이터로 채우지 않습니다. 외부 위젯 로드는 앱의 실제 원천 조회 성공을 의미하지 않습니다. 개인 계정이나 비밀키를 위젯에 넘기지 않습니다.

## 공식 계약에서 확인한 추가 사항

제공된 ZIP 이름은 v1이지만 내부 계약은 2.0.0이고 정본 조건은 35개입니다. C22~24에는 과정 사이트의 `t04_day` 봉인 영수증 정확히 2건이 사용됩니다. 앱 JSON은 참고 자료이며 영수증 발급을 대신하지 않습니다. 자동 갱신은 당일 저장값을 갱신하므로 봉인 영수증의 값과 앱에 최종 보존된 일별 값이 일치하는지 확인해야 합니다.

## v1.3 금·은 추가 조회

과제의 값 하나·하루 한 줄·실제 이틀 증빙은 기존 금(XAU)으로 고정합니다. 은(XAG)은 별도 참고 조회로 표시하며 Supabase 일별 기록에 넣지 않습니다. 현재 가격의 출처·단위·원천 시각·조회 시각·KST를 표시하고 실패 시 해당 종목의 마지막 정상값을 보존합니다. 종목 전환 시 다른 종목의 응답을 표시하지 않습니다. 추가 기능 금지 조항은 없으며 뉴스 기능은 제거했습니다. 실제 이틀 및 과정 영수증 조건은 별도로 충족해야 합니다.
