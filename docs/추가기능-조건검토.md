# v3 조건 검토

첨부 과제는 실제로 변하는 값 하나를 요구하므로 대표 검증 대상은 금(XAU)으로 고정합니다. 은·석유·밀과 원화 환산은 추가 조회 기능입니다.

| 기준 | 구현 |
|---|---|
| C03~C10 | 금 실제 USD 값·단위·출처·원천/조회 시각·KST 및 원자료·저장·표시 대조 |
| C11 | 키는 서버 환경변수만 사용. 환율은 키 없는 공개 경로 |
| C12~C19 | 금 5종 합성 실패·마지막 정상값·stale·복구 및 공식 원본 fixture 유지 |
| C20~C21 | 금 KST 날짜별 1행, 다음 날짜 새 행 |
| C22~C24 | 금 전용 서버 evidence의 최초 두 실제 날짜와 USD 변화값 |
| 공통 | 공개 URL, 개인정보/비밀값 비노출, 제출 설명 및 실제 증빙 별도 확인 |

원화 환산 실패와 석유·밀의 키 미설정은 금 완료 판정과 분리합니다. 달러 원천값이 없으면 원화를 생성하지 않습니다. 환율은 하루 1회 갱신되는 최신 제공값이며, 기준 시각을 표시합니다. 일별 기록의 원화도 현재 적용 환율을 사용한 참고값으로 당시 원화 가격을 의미하지 않습니다. 숫자 차트는 외부 제공 USD 차트로 유지됩니다.
