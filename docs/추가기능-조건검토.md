# v1.8.0 검증 페이지 개편

검증 화면은 현재 4종목 설정을 공유하지만 과제의 주 증빙 대상은 여전히 금 XAU입니다. C03~C10의 실제 금 값·출처·단위·원천/조회 시각·시간대·대조, C12~C19의 실패/복구, C20~C24의 일별 저장/실제 이틀, 공식 꾸러미 해시 및 원본 fixture 재생 기능을 유지합니다. 무로그인 /verify.html 링크도 유지합니다. 페이지 진입 시 GET으로 저장 기록만 읽으며, POST 수집은 버튼을 눌러 실행합니다. 화면 재구성은 필수 기능을 없애지 않으므로 조건과 충돌하지 않는 것으로 판단합니다.

# v1.7.0 과제 조건 검토

첨부 과제4 조건과 공식 T04 계약을 기준으로 검토했습니다. 과제의 주 대상은 금 XAU 하나로 유지하며, 부가 종목 제거와 외부 화면 재요청은 아래 조건과 충돌하지 않는 것으로 판단합니다. 실제 배포 및 이틀 증빙까지 완료되었다는 뜻은 아닙니다.

| 항목 | 구현 |
| --- | --- |
| 종목 | 금·은·석유(WTI)·밀. 레늄 제거 |
| C03~C10 | 금의 실제 값·단위·출처·두 시각·KST·원자료 대조 유지 |
| C11 | 레늄 전용 키/API 제거. Supabase 비밀값은 서버 환경변수에만 보관 |
| C12~C19, C26 | 검증 페이지의 다섯 합성 실패·마지막 정상값·복구 검사 유지 |
| C20~C24 | 금의 날짜 키·일별 저장·실제 이틀 대조 유지. 부가 종목은 기록에 섞지 않음 |
| 석유·밀 갱신 | 위젯과 차트를 함께 재요청. 30초 간격 및 숨겨진 탭 일시정지. 화면 요청 시각을 가격 기준 시각으로 표시하지 않음 |
| 외부 위젯 | OANDA CFD 참고가격임을 명시. iframe 내용으로 fresh 성공이나 실제 이틀 증빙을 판정하지 않음 |

실제 별도 확인: 서로 다른 KST 날짜의 금 기록과 변화값, 과정 발급 t04_day 영수증 2건, 무로그인 결과물·검증 URL, 전체 commit HTTPS 소스 URL. 화면 재요청으로 제공자의 휴장·지연·외부 표시 제한을 해소할 수는 없습니다.
