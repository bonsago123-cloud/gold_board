## 재현 명령

```bash
npm test
npm run build
```

선택적 SQL 검증은 본인 PC의 별도 테스트 폴더에 `@electric-sql/pglite`를 설치한 뒤 해당 패키지의 절대 모듈 경로를 넣어 실행할 수 있습니다. 앱 런타임 의존성은 아닙니다.

```bash
node scripts/check-sql.mjs /설치위치/node_modules/@electric-sql/pglite/dist/index.js
```

SQL 검사는 메모리의 폐기 가능한 DB만 사용합니다. 테스트 중 과거 날짜의 합성 행을 생성하지만 Supabase로 전송하지 않고 실제 증빙으로 저장하지 않습니다.
