- 소스 커밋 / 수정 여부:
- 실제 URL / 배포 버전 확인 근거:
- 브라우저·실행 환경 / 접근 제한:
- 읽은 과제 조건 경로 / 공통 상한 및 실제 사용량 근거:
- 기능 목록 수집 범위 / 발견한 추가 기능:
