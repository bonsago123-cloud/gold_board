# 다음 AI는 여기서 시작

사용자가 저장소와 “이어서 진행해”만 전달하면 **AGENTS.md**를 읽고 `npm ci` → `npm run handoff:resume`을 실행하세요.
종료할 때 `npm run handoff:finish`가 다음 AI용 상태·실패 원인·다음 행동·7항목 문서를 자동 갱신합니다.
고정 검사 10/10만으로 완료가 아닙니다. 실제 API/배포/브라우저/제출 증빙까지 확인합니다.
**필수 추가 절차:** [실제 사이트 전체 기능 실행](docs/handoff/SITE-CHECK.md). 시작·종료 때 모든 기능을 직접 사용하고, 실패 수정·재검사 결과를 다음 AI에게 남깁니다. 기존 자동 검사가 통과하거나 브라우저 검사를 생략해도 이 절차는 별도로 수행합니다.

자세한 절차와 상태 의미: [연속 인수인계](docs/handoff/PROTOCOL.md).
