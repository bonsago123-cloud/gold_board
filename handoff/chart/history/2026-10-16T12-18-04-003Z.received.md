# 현재 인수인계 — BTC 차트 / A 준비 → B 구현 대기

## 1. 목표
BTC 현재가 아래에 금·은과 같은 방식의 비트코인 차트 한 기능을 추가한다. 환율 변경은 하지 않는다. A는 고정 검사·자동화·인계 준비만 수행하고 B가 실제 차트를 구현한다.

## 2. 현재 상태
A_HANDOFF / 구현 미완료 / 제출 불가. 시작 소스 8f8614f4b807596aeb5370537a3340505eb368c5. A 종료 업로드 커밋은 아직 없음(null). ZIP을 GitHub에 업로드한 실제 커밋을 B가 기록해야 한다. 시작 HEAD를 종료 커밋으로 대신 쓰지 않는다.
현재 BTC 조회 코드는 원격에 존재하지만 BTC 차트 DOM은 없다. 이전 현재가 인계는 docs/task5/bitcoin-chart/previous-quote-handoff.md에 원문 보존했다. 과거 BLOCKED/미확인도 그대로 남아 있다.
차트용 별도 고정10개·freeze·30분/사용자 작업지시10건 상한·시작 기록·동일 최초 요청·검사 실행기를 추가했다. handoff 명령과 기존 Actions를 차트 실행기로 연결했다. 이전 BTC 현재가 고정10개는 회귀로 실행한다.

## 3. 실행 명령
Node24, Git. 새 폴더에서 npm ci → npx playwright install chromium → npm run handoff:resume → npm run chart:check. NEXT.md의 구현 순서로 작업하고 npm run handoff:finish. 종료코드1=미완료,2=설정오류. 실패해도 나머지 검사를 실행한다. 상세 명령 의미는 docs/task5/bitcoin-chart/NEXT.md.
B는 session.json service/model을 실제 값으로 채운다. A 서비스는 ChatGPT, 정확한 모델은 미확인. 과제상 다른 서비스 또는 확인 가능한 다른 모델이 필요하다.

## 4. 통과 검사
이번 A 준비 중 기존 BTC 현재가 고정검사 10/10 PASS, 회귀44/44 PASS, build PASS. 차트 고정검사 및 전체 사이트 실행 결과는 handoff/chart/latest.json과 docs/task5/bitcoin-chart/a-end.json을 함께 확인한다. 실제 차트는 구현하지 않았다. 이전 PASS 기록을 새 차트 PASS로 전용하지 않는다.

## 5. 남은 문제
BTC 차트 구현 없음. Chromium 설치가 손상된 다운로드 응답으로 실패하는 환경 문제가 관찰됐다. 브라우저를 실행하지 못한 항목은 UNVERIFIED. 실제 사이트의 모든 기능·BTC 차트 확대축소·외부 데이터·배포 파일 일치·모델 차이·학생 판단·공개 비교보고서는 B의 실제 실행/확인이 필요하다.
현재 runner의 실제 검증/제출 gate는 명시적으로 UNVERIFIED이며 자동 완료 판정은 준비되지 않았다. B가 증거를 검증하는 부분을 확장할 수 있지만 고정10개/입력/기대값/freeze는 변경할 수 없다. 이유 없이 PASS 플래그만 넣으면 안 된다.

## 6. 다음 행동
사용자가 ZIP을 루트 상대경로 그대로 업로드 → 다른 모델/서비스 새 대화의 B에게 저장소만 제공 → B가 AGENTS.md와 docs/task5/bitcoin-chart/NEXT.md를 읽고 resume 실행. 받은 current.md 원문 해시와 A 인계 원문 해시를 대조한다. 첫 기능 실패 예상은 T05-BCH01(차트 UI 없음); 실행 못 했다면 실패 확정으로 쓰지 않는다.
B는 수정·재검사·전체 사이트 각 기능 실행·실제 증거 기록·7항목 인계 갱신·업로드 ZIP 제공까지 수행한다. Actions는 검사와 artifact 저장만 자동화하며 AI를 자동 호출하지 않는다.
